# Go RPG API

This is a minimal backend API written in Go that simulates a simple text-based RPG system, where characters can be created, healed, meditate, attack each other, and engage in random battles.

The project was built as a test to explore API development within the **Firebase Studio** environment.

## Stack

- **Go (Golang)**
- **SQLite**
- **REST Client (VS Code Extension)** — Used to test API endpoints directly within the editor
